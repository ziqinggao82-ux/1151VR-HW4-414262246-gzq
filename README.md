
## 一、匯入素材
  我先把平台切換為 Android,匯入直升機模型和三個音檔。把直升機放進 player,再另外建一個 Model 來調整機頭方向,這樣飛行方向就不會亂掉。

## 二、做地形
  我用 Terrain 捏出有高低不等的山。再下載草地和岩石貼圖幫地形上色，並讓撞到山會被判定為撞擊。
## 三、飛行控制
  直升機會自動往前飛，電腦用方向鍵上下左右移動，手機用傾斜控制。我限制了飛行範圍，不會超過左右邊界，最低在地平面，也有限制最高高度。相機   固定在機尾後方往前看。
## 四、生命值與遊戲結束
  右上角放了三顆愛心，撞到一次就少一顆。三顆都沒了就跳出 Game Over，過兩秒再出現「再玩一次」按鈕。
## 五、通過山與通關
  因為有太多障礙物，且山形狀不規則，所以我改用位置來判斷:每當飛過250長度就算通過，撥放一次通過音效，總共有7次，及最後飛到終點播放通關音  效並顯示 You Win。輸贏都共用同一顆「再玩一次」按鈕，點擊能重來。
## 六、加入音效
  加入飛行聲、輕撞聲、重撞聲、通過聲和通關聲。飛行聲會一直循環。
## 七、輸出到手機
  打開手機的開發者模式與和USB 偵錯，在 Build Profiles 確認平台為 Android，在 Player Settings 設定 Package Name 和橫式畫面，按下   Build And Run 輸出 APK。
